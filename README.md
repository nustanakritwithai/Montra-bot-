# Montra Bot

หน้า GitHub Pages อยู่ใน `docs/` ส่วน `server/dashboard.mjs` อ่านสถานะและเหตุการณ์จากบอตบน VPS และรับคำสั่งที่กำหนดไว้ผ่าน API

API ฟังที่ `127.0.0.1:34785` และใช้ reverse proxy HTTPS ที่ `/bot-admin-api/` ไฟล์ตั้งค่าใน VPS ระบุ `root` เป็นโฟลเดอร์บอต `origin` เป็น origin ของ GitHub Pages และ `key` เป็นคีย์สุ่ม 32 ไบต์ในรูปเลขฐานสิบหก เก็บไฟล์ตั้งค่านี้ไว้นอก Git

แดชบอร์ดอัปเดตทุก 6 วินาที อ่านรายชื่อทีมกิลด์และกำลังสำรองจาก fighter-role.mjs ใน root ของบอต และอ่านทะเบียนศึกแบบอ่านอย่างเดียวจาก guilds.sqlite ระบุพาธอื่นได้ด้วย warDatabase ในไฟล์ตั้งค่า VPS ข้อมูลทั้งหมดต้องใช้คีย์แดชบอร์ด ปุ่มจัดการรองรับรีสตาร์ตบอตหลักทั้งสามตัว ส่งบอตทดลองไปจุดหมาย และเปิดหรือหยุดบอตพ่อค้า

ยอดบอตหลักรวมทีมกิลด์และบอตหลักทั้งสามตัว โดยนับกำลังสำรองแยกต่างหาก มุมมองเป้าหมายแม่ทัพอ่านจากสถานะบอต ส่วนศึกที่เปิดและผลศึกอ่านจากฐานข้อมูลเกม มุมมองพ่อค้าแสดงยอดต่อรอบเชื่อมต่อและแจ้งเมื่อพบการเดินทางกลับไปมาสองรอบจากบันทึกการเข้าแผนที่

รันทดสอบ API และการสรุปสถานะด้วย `node --test server/dashboard.test.mjs server/fleet.test.mjs`
