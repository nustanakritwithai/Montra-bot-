# Montra Bot

หน้า GitHub Pages อยู่ใน `docs/` ส่วน `server/dashboard.mjs` อ่านสถานะและเหตุการณ์จากบอตบน VPS และรับคำสั่งที่กำหนดไว้ผ่าน API

API ฟังที่ `127.0.0.1:34785` และใช้ reverse proxy HTTPS ที่ `/bot-admin-api/` ไฟล์ตั้งค่าใน VPS ระบุ `root` เป็นโฟลเดอร์บอต `origin` เป็น origin ของ GitHub Pages และ `key` เป็นคีย์สุ่ม 32 ไบต์ในรูปเลขฐานสิบหก เก็บไฟล์ตั้งค่านี้ไว้นอก Git

แดชบอร์ดอัปเดตทุก 6 วินาที ข้อมูลจากบอตและประวัติต้องผ่านการยืนยันคีย์ รองรับรีสตาร์ตทุกตัว ส่งบอตทดลองไปจุดหมาย และเปิดหรือหยุดบอตพ่อค้า

รันทดสอบ API ด้วย `node --test server/dashboard.test.mjs`
